# Claude Norsk Learning

A collection of Claude Code skills to help me learn Norwegian.

## Skills

### 1. learn-norsk-video (`SKILL.md`)

Downloads subtitles from a Norwegian video and translates them to English, displaying each line side by side (Norwegian + English) for easy reading and learning.

**Works with:** NRK videos (e.g. tv.nrk.no)

**Requirements:** `yt-dlp` and `ffmpeg` (install via `brew install yt-dlp ffmpeg`)

**Usage:** Give Claude a link to an NRK video and say you want to learn Norwegian from it. Claude will download the subtitles and present each sentence in both languages.
